# Security Policy

## Supported version

Only the latest commit on the `main` branch is supported with security updates.

## Report a vulnerability privately

Do not disclose a vulnerability in a public issue, discussion, pull request, or social post.

Use GitHub private vulnerability reporting:

https://github.com/mosta1570-design/routebudget-eu/security/advisories/new

Include affected URL or file, impact, reproduction steps, and a minimal proof of concept when safe. Do not include real credentials, personal data, or destructive payloads.

The maintainer will review the report privately and coordinate a fix before public disclosure.
